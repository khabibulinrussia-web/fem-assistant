# ФЭМ-ассистент

Веб-приложение для ввода данных и автоматического расчёта финансово-экономической модели (ФЭМ).

## Стек

- **Frontend**: React + Next.js + Tailwind CSS
- **Backend**: Python + FastAPI + openpyxl
- **БД**: PostgreSQL (Supabase)
- **Деплой**: Vercel + Supabase

## Структура

```
fem-assistant/
├── frontend/          # Next.js (React)
│   ├── app/           # страницы и API-роуты
│   ├── components/    # UI-компоненты
│   └── lib/           # утилиты
├── backend/           # Python FastAPI
│   ├── main.py        # API-эндпоинты
│   ├── calculations/  # логика ФЭМ
│   └── requirements.txt
```
